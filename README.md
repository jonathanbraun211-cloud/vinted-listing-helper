# Vinted Listing Helper

Baue eine moderne, mobile Web-App für Vinted-Verkäufer als einfache, sichere und preiswertere Alternative zu Vintz.ai.

Kernfunktionen:
- Mobile-First Interface: Schneller Foto-Upload (Vorderseite des Kleidungsstücks + Foto vom Waschetikett/Größenlabel) direkt vom Smartphone oder per Drag-and-Drop.
- KI-Analyse & Erkennung: Liest automatisch Artikelart, Marke, Größe, Materialzusammensetzung und Zustand aus den Fotos aus und liefert einen realistischen Preisvorschlag basierend auf aktuellen Second-Hand-Preisen.
- Inserat-Vorschau: Generiert sofort einen Vinted-optimierten Titel, eine sympathische Verkaufsbeschreibung inklusive relevanter Hashtags und alle strukturierten Attribute.
- 1-Klick-Übernahme: Alle Daten mit einem Klick kopierbar oder direkt für das Vinted-Listing vorbereitet (ohne riskante Bots oder Bann-Gefahr).
- Transparentes Credit-System: Zeigt kostenlose Test-Inserate und günstige Credit-Pakete (z. B. 50 Inserate für 4,99 €) mit klarer Marge.
- Clean, schnelles und responsives Design mit modernem Look.
